# 💎 Rold-Gold Jewellery Website

A premium jewellery ecommerce website built with modern web technologies to showcase elegant designs and facilitate user-friendly shopping experiences.

🔗 Live Demo:-> https://rold-gold-jewellary.vercel.app/

---

## 🧰 Tech Stack

- **Next.js (App Router)** – Full-stack React framework
- **TypeScript** – Static typing for better maintainability
- **Tailwind CSS** – Utility-first CSS framework
- **PNPM** – Fast, disk-efficient package manager
- **Vercel** – Deployment and hosting platform

---

## 📂 Folder Structure Overview

```
app/                  # App Router structure
  ├── about/          # About page
  ├── api/            # API routes
  ├── auth/           # Authentication pages
  ├── cart/           # Cart functionality
  ├── checkout/       # Checkout process
  ├── components/     # Page-specific components
  ├── contact/        # Contact page
  ├── contexts/       # React Context Providers
  ├── products/       # Product listing and detail pages
  ├── providers/      # Global providers (e.g., theme, auth)
  ├── styles/         # Global styles
  ├── ClientLayout.tsx
  ├── layout.tsx
  ├── loading.tsx
  └── page.tsx        # Homepage

components/           # Reusable UI components
hooks/                # Custom React hooks
lib/                  # Utility functions or libraries
public/               # Static assets (images, fonts, etc.)
styles/               # Global CSS and Tailwind base styles
.env.local            # Local environment variables
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/rold-gold-jewellary.git
cd rold-gold-jewellary
```

### 2. Install dependencies

```bash
pnpm install
# or
npm install
```

### 3. Start the development server

```bash
pnpm dev
# or
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the app.

---

## 🧪 Available Scripts

- `dev` – Run development server
- `build` – Build project for production
- `start` – Start production server
- `lint` – Run ESLint for code quality
- `format` – Format code using Prettier (if configured)

## 🌐 Deployment

Deployed on **Vercel** with automatic CI/CD via GitHub integration.

To deploy manually:
```bash
pnpm build
pnpm start
```
